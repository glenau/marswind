Marswind слухає те, що грає на вашій машині - відео на YouTube, дзвінок у Google
Meet, Teams чи Zoom, локальний відеофайл - розпізнає мовлення й перекладає його
вибраною вами мовою просто під час розмови.

Жодних API-ключів, облікових записів чи інтернету. Моделі завантажуються один
раз і далі працюють локально; звук лишається в пам'яті, не записується на диск і
нікуди не надсилається.

## Що він уміє

- **Захоплює системний звук** без віртуального аудіодрайвера - усе, що грає
  машина, або один застосунок, наприклад браузер
- **Розпізнає мовлення** через whisper.cpp на GPU: субтитри дописуються в міру
  вимовляння, а не переписуються під читачем
- **Перекладає під час мовлення** - слова йдуть до перекладача одразу після
  фіксації, а не по завершенні речення, і переклад надходить по слову
- **Керує моделями** прямо в застосунку: сім моделей розпізнавання та п'ять
  моделей перекладу, із прогресом завантаження та перевіркою SHA-256
- **Записує кожну сесію** - їх можна переглядати та експортувати в текст,
  субтитри (`.srt`) чи JSON разом із таймкодами
- **Постачається зі зразками аудіо**, щоб спробувати без пошуку відео
- **Говорить тринадцятьма мовами** - тими самими, якими перекладає - у світлій чи
  темній темі, з розміром тексту, що масштабує весь інтерфейс, а не лише шрифт

### Мови

Англійська, російська, німецька, іспанська, французька, італійська,
португальська, польська, турецька, українська, китайська, японська та корейська -
і як мови перекладу, і як мова самого вікна. Мова мовлення за замовчуванням
визначається зі звуку, а розпізнавання охоплює все, що вміє whisper.

## Як це працює

```
Системний звук  →  ресемплінг у 16 кГц моно  →  детектор мовлення (Silero)
                →  розпізнавання мовлення (whisper.cpp)
                →  переклад (llama.cpp, в окремому процесі)
                →  розшифровка: оригінал ліворуч, переклад поруч
```

Усе, що нижче інтерфейсу, написано на Rust і працює на виділених потоках, а
переклад винесено в окремий бінарник, бо whisper.cpp і llama.cpp не можуть жити
в одному процесі. Будову та обґрунтування описано в
[docs/ARCHITECTURE.md](../ARCHITECTURE.md).

Виміряно на Apple Silicon з типовими моделями на синтетичному корпусі з
[tests/](../../tests/README.md) - медіани трьох прогонів на кліп: перший субтитр
приблизно через 6 секунд, наступний - кожні 2-3 секунди, помилок за словами від
4% на чистій начитці до 23% на кліпі з власними назвами й цифрами. Розпізнавання
недетерміноване, і один прогон гуляє приблизно на двадцять пунктів, тож це
медіани, а не результати; як отримано ці числа, описано поруч зі стендом.

## Підтримка платформ

| Платформа | Стан |
|---|---|
| **macOS 14.4+** | Підтримується - Core Audio process taps, Metal |
| **Windows** | У розробці - WASAPI loopback |
| **Linux** | У розробці - PipeWire |

Застосунок уже збирається й запускається на Windows та Linux, але захоплення
звуку там повідомляє про свою недоступність - тобто вікно, якому нема чого
слухати. Усе, що вище захоплення, не залежить від платформи й уже працює.

Віртуальний аудіодрайвер на кшталт BlackHole **не потрібен** на жодній
платформі: захоплення йде через рідні API системи.

## Встановлення

### Завантажити

В [останньому релізі](https://github.com/glenau/marswind/releases/latest) є
`.dmg`. Відкрийте його, перетягніть Marswind у Applications - і все. Близько
13 МБ: моделі завантажуються пізніше й лише ті, які ви оберете.

**З першого разу macOS відмовиться його відкрити.** Образ підписаний, але не
нотаризований: платного сертифіката Developer ID у проєкту немає, а все без
нього Gatekeeper вважає застосунком від невідомого розробника. Обхід такий:

1. Відкрийте застосунок і дайте системі його заблокувати. Натисніть **Done**, а
   не «Move to Bin».
2. **Системні налаштування → Конфіденційність і безпека**, прокрутіть униз до
   розділу **Безпека**. Там буде рядок про те, що Marswind заблоковано, і поруч
   кнопка **Усе одно відкрити**.
3. Натисніть її, підтвердіть Touch ID або паролем і підтвердіть ще раз.

macOS запитає один раз і запам'ятає. Кнопка з'являється лише після заблокованого
запуску й живе близько години; якщо її немає, запустіть застосунок ще раз.

Правий клік по застосунку → «Відкрити» - це попередній спосіб зробити те саме,
він ще працює на macOS 14. У macOS 15 його прибрали, тож шлях через
налаштування - єдиний, який працює всюди.

### Або зібрати

```bash
git clone https://github.com/glenau/marswind.git
cd marswind
npm install
npm run install:macos
```

Це збере перекладач, збере релізний бандл, підпише його ad-hoc підписом і
скопіює в `/Applications/Marswind.app`. Перша збірка триває кілька хвилин -
whisper.cpp і llama.cpp компілюються з коду. Більше нічого не потрібно: ні
підмодулів, ні бібліотек, які довелося б ставити руками, ні моделей, які треба
завантажити заздалегідь.

### Перший запуск

1. `open /Applications/Marswind.app`
2. macOS попросить дозвіл **Запис звуку**. Погодьтеся - без нього застосунок
   нічого не почує. Якщо відмовили, дозвіл можна надати знову в Системних
   налаштуваннях → Конфіденційність і безпека → Запис звуку.
3. Відкрийте **Налаштування** й завантажте одну модель розпізнавання та одну
   модель перекладу. `Large v3 Turbo (compressed)` і `Qwen3 4B Instruct` -
   типові для машини з 16 ГБ і більше; `Small` та `Qwen3 1.7B` вміщаються у 8 ГБ.
   Близько 3 ГБ завантаження, кожне перевіряється за опублікованою контрольною
   сумою. Поруч із кожною моделлю вказано її ліцензію - див.
   [docs/MODELS.md](../MODELS.md).
4. Натисніть **Почати слухати** й увімкніть щось із мовленням. У налаштуваннях
   є чотири приклади аудіо, якщо не хочеться шукати відео.

Дві речі про самостійно зібрану копію:

- **Підпис ad-hoc.** Для конкретної збірки він стабільний, тож дозвіл на звук
  зберігається - але перезбірка дає нову ідентичність, і macOS запитає знову.
  Усуває це сертифікат Developer ID, якого поки немає.
- **Не переміщуйте застосунок під час роботи.** Для оновлення запустіть
  `npm run install:macos` ще раз - він замінює `/Applications/Marswind.app` на
  місці.

### Збірка образу диска

```bash
npm run build:dmg
```

Збирає релізний бандл, підписує його та пакує в
`src-tauri/target/Marswind-<версія>-<арх>.dmg` - той самий образ, який
додається до релізу, з тим самим застереженням про Gatekeeper, що й вище.
Чек-лист навколо нього - у [docs/RELEASING.md](../RELEASING.md).

## Розробка

`tauri dev` створює голий виконуваний файл без `Info.plist` і без підпису, а
Core Audio process taps у такому вигляді не працюють. Натомість користуйтеся
командою, яка збирає налагоджувальний бандл, підписує його та запускає:

```bash
npm run dev:macos
```

| Команда | Що робить |
|---|---|
| `npm run dev:macos` | зібрати, підписати та запустити налагоджувальний бандл |
| `npm run install:macos` | зібрати релізний бандл і встановити його |
| `npm run check` | типи Svelte і TypeScript |
| `npm run build:dmg` | підписаний `.dmg`, щоб комусь передати |
| `npm run build:sidecar` | лише перекладач |
| `npm run build:icons` | перемалювати іконку зі `scripts/make-icon.py` |
| `npm run build:social` | перемалювати картку, яку GitHub показує за посиланням |
| `npm run licenses` | перезібрати `THIRD-PARTY-NOTICES.md` з lock-файлів |

CI немає: whisper.cpp і llama.cpp компілюються з коду, а стенд програє звук
через системний вивід, тож усі перевірки - локальні команди. Їх перелічено в
[CONTRIBUTING.md](../../CONTRIBUTING.md).

## Тести

Юніт-тести покривають чисту логіку; скрипти в [tests/](../../tests/README.md)
програють звук через системний вивід і оцінюють те, що виходить із справжнього
конвеєра - розпізнавання, переклад і затримки разом.

```bash
npm run build:sidecar
cargo test --manifest-path src-tauri/Cargo.toml
```

Перший рядок потрібен один раз, і далі лише після `cargo clean`. Tauri кладе
перекладач у бандл як sidecar, тому його build-скрипт узагалі відмовляється
збирати `src-tauri`, доки бінарника немає: на свіжому клоні `cargo test` сам по
собі спиняється на `resource path 'binaries/marswind-translator-…' doesn't
exist`. Будь-яка команда `npm run` робить цей крок за вас, а виклик `cargo`
напряму - ні.

Скриптам стенда потрібен зібраний і підписаний бандл та встановлені моделі:

```bash
npm run dev:macos
tests/run-capture.sh
tests/run-asr.sh
tests/run-pipeline.sh
```

Один прогін по корпусу коливається приблизно на двадцять пунктів помилок за
словами, тож окреме число саме по собі нічого не означає. Порівнюйте медіани за
кількома прогонами й читайте розшифровки, а не лише оцінки.

## Приватність

- Звук захоплюється, ресемплиться й розпізнається **в пам'яті**. Він не
  записується на диск і нікуди не надсилається.
- Єдиний мережевий трафік - завантаження моделей, які ви самі обрали. Після
  встановлення застосунок узагалі не ходить у мережу.
- Ні телеметрії, ні аналітики, ні звітів про збої, ні облікових записів.
- Розшифровки пишуться лише в каталог даних застосунку, щоб розділ «Історія» мав
  що показати. Видалити їх можна прямо із застосунку.
