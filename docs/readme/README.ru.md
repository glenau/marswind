Marswind слушает то, что играет на вашей машине - видео на YouTube, звонок в
Google Meet, Teams или Zoom, локальный видеофайл - распознаёт речь и переводит
её на выбранный вами язык прямо по ходу разговора.

Никаких API-ключей, аккаунтов и интернета. Модели скачиваются один раз и дальше
работают локально; звук остаётся в памяти, не пишется на диск и никуда не
отправляется.

## Что он умеет

- **Захватывает системный звук** без виртуального аудиодрайвера - всё, что
  играет машина, или одно приложение, например браузер
- **Распознаёт речь** через whisper.cpp на GPU: субтитры дописываются по мере
  произнесения, а не переписываются под читателем
- **Переводит по ходу речи** - слова уходят переводчику сразу после фиксации, а
  не после окончания предложения, и перевод приходит по слову
- **Управляет моделями** прямо в приложении: семь моделей распознавания и пять
  моделей перевода, загрузка с прогрессом и проверкой SHA-256
- **Записывает каждую сессию** - их можно просматривать и выгружать в текст,
  субтитры (`.srt`) или JSON вместе с тайм-кодами
- **Идёт с примерами аудио**, чтобы попробовать приложение, не ища видео
- **Говорит на тринадцати языках** - тех же, на которые переводит - в светлой
  или тёмной теме, с размером текста, который масштабирует весь интерфейс, а не
  только шрифт

### Языки

Английский, русский, немецкий, испанский, французский, итальянский,
португальский, польский, турецкий, украинский, китайский, японский и корейский -
и как языки перевода, и как язык самого окна. Язык речи по умолчанию
определяется из звука, и распознавание охватывает всё, что умеет whisper.

## Как это работает

```
Системный звук  →  ресемплинг в 16 кГц моно  →  детектор речи (Silero)
                →  распознавание речи (whisper.cpp)
                →  перевод (llama.cpp, в отдельном процессе)
                →  расшифровка: оригинал слева, перевод рядом
```

Всё, что ниже интерфейса, написано на Rust и работает на выделенных потоках, а
перевод вынесен в отдельный бинарник, потому что whisper.cpp и llama.cpp не
могут жить в одном процессе. Устройство и обоснования - в
[docs/ARCHITECTURE.md](../ARCHITECTURE.md).

Измерено на Apple Silicon с моделями по умолчанию на синтетическом корпусе из
[tests/](../../tests/README.md) - медианы трёх прогонов на клип: первый субтитр
примерно через 6 секунд, следующий - каждые 2-3 секунды, ошибок по словам от 4%
на чистой начитке до 23% на клипе с именами собственными и цифрами.
Распознавание недетерминировано, и один прогон гуляет примерно на двадцать
пунктов, так что это медианы, а не результаты; как получаются эти числа, описано
рядом с самим стендом.

## Поддержка платформ

| Платформа | Состояние |
|---|---|
| **macOS 14.4+** | Поддерживается - Core Audio process taps, Metal |
| **Windows** | В разработке - WASAPI loopback |
| **Linux** | В разработке - PipeWire |

Приложение уже собирается и запускается на Windows и Linux, но захват звука там
сообщает о своей недоступности - то есть окно, которому нечего слушать. Всё, что
выше захвата, не зависит от платформы и уже работает.

Виртуальный аудиодрайвер вроде BlackHole **не нужен** ни на одной платформе:
захват идёт через нативные API системы.

## Требования

| | |
|---|---|
| macOS | 14.4 или новее, Apple Silicon или Intel |
| Память | 8 ГБ только для распознавания, 16 ГБ вместе с переводом |
| Диск | 0,5-4,5 ГБ под выбранные модели |
| Для сборки | [Rust](https://rustup.rs), [Node.js](https://nodejs.org) 20+, cmake (`brew install cmake`) |

## Установка

### Скачать

В [последнем релизе](https://github.com/glenau/marswind/releases/latest) есть
`.dmg`. Откройте его, перетащите Marswind в Applications - и всё. Около 13 МБ:
модели скачиваются позже и только те, которые вы выберете.

**С первого раза macOS откажется его открыть.** Образ подписан, но не
нотаризован: платного сертификата Developer ID у проекта нет, а всё без него
Gatekeeper считает приложением от неустановленного разработчика. Обходится это
так:

1. Откройте приложение и дайте системе его заблокировать. Нажмите **Done**, а не
   «Move to Bin».
2. **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз
   до раздела **Безопасность**. Там будет строка о том, что Marswind
   заблокирован, и рядом кнопка **Открыть всё равно**.
3. Нажмите её, подтвердите Touch ID или паролем и подтвердите ещё раз.

macOS спросит один раз и запомнит. Кнопка появляется только после
заблокированного запуска и живёт около часа; если её нет, запустите приложение
снова.

Правый клик по приложению → «Открыть» - это прежний способ сделать то же самое,
он ещё работает на macOS 14. В macOS 15 его убрали, поэтому путь через
настройки - единственный, который работает везде.

### Или собрать

```bash
git clone https://github.com/glenau/marswind.git
cd marswind
npm install
npm run install:macos
```

Это соберёт переводчик, соберёт релизный бандл, подпишет его ad-hoc подписью и
скопирует в `/Applications/Marswind.app`. Первая сборка занимает несколько минут -
whisper.cpp и llama.cpp компилируются из исходников. Больше ничего не нужно:
ни подмодулей, ни библиотек, которые пришлось бы ставить руками, ни моделей,
которые надо скачать заранее.

### Первый запуск

1. `open /Applications/Marswind.app`
2. macOS попросит разрешение **Запись звука**. Согласитесь - без него
   приложение ничего не услышит. Если отказали, разрешение можно выдать снова в
   Системных настройках → Конфиденциальность и безопасность → Запись звука.
3. Откройте **Настройки** и скачайте одну модель распознавания и одну модель
   перевода. `Large v3 Turbo (compressed)` и `Qwen3 4B Instruct` - умолчания для
   машины с 16 ГБ и больше; `Small` и `Qwen3 1.7B` помещаются в 8 ГБ. Примерно
   3 ГБ загрузки, каждая проверяется по опубликованной контрольной сумме. Рядом
   с каждой моделью указана её лицензия - см. [docs/MODELS.md](../MODELS.md).
4. Нажмите **Начать слушать** и включите что-нибудь с речью. В настройках есть
   четыре примера аудио, если не хочется искать видео.

Две вещи про самостоятельно собранную копию:

- **Подпись ad-hoc.** Для конкретной сборки она стабильна, поэтому разрешение на
  звук сохраняется - но пересборка даёт новую подпись, и macOS спросит снова.
  Убирает это сертификат Developer ID, которого пока нет.
- **Не перемещайте приложение во время работы.** Для обновления запустите
  `npm run install:macos` заново - он заменяет `/Applications/Marswind.app` на
  месте.

### Сборка образа диска

```bash
npm run build:dmg
```

Собирает релизный бандл, подписывает его и упаковывает в
`src-tauri/target/Marswind-<версия>-<арх>.dmg` - тот самый образ, который
прикладывается к релизу, с той же оговоркой про Gatekeeper, что и выше.
Чек-лист вокруг него - в [docs/RELEASING.md](../RELEASING.md).

## Разработка

`tauri dev` создаёт голый исполняемый файл без `Info.plist` и без подписи, а
Core Audio process taps в таком виде не работают. Вместо этого используйте
команду, которая собирает отладочный бандл, подписывает его и запускает:

```bash
npm run dev:macos
```

| Команда | Что делает |
|---|---|
| `npm run dev:macos` | собрать, подписать и запустить отладочный бандл |
| `npm run install:macos` | собрать релизный бандл и установить его |
| `npm run check` | типы Svelte и TypeScript |
| `npm run build:dmg` | подписанный `.dmg`, чтобы кому-то передать |
| `npm run build:sidecar` | только переводчик |
| `npm run build:icons` | перерисовать иконку из `scripts/make-icon.py` |
| `npm run licenses` | пересобрать `THIRD-PARTY-NOTICES.md` из lock-файлов |

CI нет: whisper.cpp и llama.cpp компилируются из исходников, а стенд проигрывает
звук через системный вывод, поэтому все проверки - локальные команды. Их список
в [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Тесты

Юнит-тесты покрывают чистую логику; скрипты в [tests/](../../tests/README.md)
проигрывают звук через системный вывод и оценивают то, что выходит из настоящего
конвейера - распознавание, перевод и задержки вместе.

```bash
npm run build:sidecar
cargo test --manifest-path src-tauri/Cargo.toml
```

Первая строка нужна один раз, и дальше только после `cargo clean`. Tauri
кладёт переводчик в бандл как sidecar, поэтому его build-скрипт вообще
отказывается собирать `src-tauri`, пока бинарника нет: на свежем клоне
`cargo test` сам по себе останавливается на
`resource path 'binaries/marswind-translator-…' doesn't exist`. Любая команда
`npm run` делает этот шаг за вас, а вызов `cargo` напрямую - нет.

Скриптам стенда нужен собранный и подписанный бандл и установленные модели:

```bash
npm run dev:macos
tests/run-capture.sh
tests/run-asr.sh
tests/run-pipeline.sh
```

Один прогон по корпусу гуляет примерно на двадцать пунктов ошибок по словам, так
что отдельное число само по себе ничего не значит. Сравнивайте медианы по
нескольким прогонам и читайте расшифровки, а не только оценки.

## Приватность

- Звук захватывается, ресемплится и распознаётся **в памяти**. Он не пишется на
  диск и никуда не отправляется.
- Единственный сетевой трафик - загрузка моделей, которые вы сами выбрали. После
  установки приложение не ходит в сеть вообще.
- Ни телеметрии, ни аналитики, ни отчётов о падениях, ни аккаунта.
- Расшифровки пишутся только в каталог данных приложения, чтобы разделу «История»
  было что показать. Удалить их можно прямо из приложения.
